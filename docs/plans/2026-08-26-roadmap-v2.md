### Data Additions (`lib/account.ts`)
```typescript
// Activity data for graph
export interface ActivityData {
  weeks: Array<{
    weekStart: string;      // ISO date (Monday)
    activeDays: number;     // 0-7
    totalEvents: number;
  }>;
  currentStreak: number;    // consecutive active days
  longestStreak: number;
}

// Subscription timeline
export interface SubscriptionTimeline {
  activeSubscriptions: Array<{
    yearId: string;
    yearLabel: string;
    subjectId: string | null;
    subjectTitle: string | null;
    startedAt: string;
    endsAt: string;
    daysRemaining: number;
    progressPct: number;    // elapsed / total
  }>;
}
```

## Visual Design — Activity Graph

**Creative approach**: Custom SVG with:
- **Gradient area fill** — accent color fading to transparent
- **Animated path drawing** — stroke-dashoffset on mount
- **Interactive dots** — hover/tap shows tooltip with date + event count
- **Weekend highlighting** — subtle vertical bands
- **Current week indicator** — pulsing dot
- **Subscription overlay** — thin line showing subscription period

**Tech**: Pure SVG + CSS animations (no chart library dependency, keeps bundle small)

## Creative Visualization Details

### Activity Graph SVG Structure
```
<svg viewBox="0 0 100% 120" preserveAspectRatio="none">
  <!-- Weekend bands -->
  <g class="weekend-bands">...</g>
  
  <!-- Subscription period overlay -->
  <g class="subscription-overlay">...</g>
  
  <!-- Area fill (gradient) -->
  <defs>
    <linearGradient id="activity-gradient" x1="0" y1="0" x2="0" y2="1">
      <stop offset="0%" stop-color="var(--color-accent)" stop-opacity="0.3"/>
      <stop offset="100%" stop-color="var(--color-accent)" stop-opacity="0"/>
    </linearGradient>
  </defs>
  <path class="activity-area" fill="url(#activity-gradient)" />
  
  <!-- Line path (animated draw) -->
  <path class="activity-line" stroke="var(--color-accent)" stroke-width="2" 
        stroke-dasharray="1000" stroke-dashoffset="1000" />
  
  <!-- Interactive dots -->
  <g class="activity-dots">...</g>
  
  <!-- Current week pulse -->
  <circle class="current-week-pulse" ... />
</svg>
```

### Animations (CSS)
```css
@keyframes drawLine {
  to { stroke-dashoffset: 0; }
}
.activity-line { animation: drawLine 1.2s ease-out forwards; }

@keyframes pulse {
  0%, 100% { opacity: 0.4; transform: scale(1); }
  50% { opacity: 1; transform: scale(1.3); }
}
.current-week-pulse { animation: pulse 2s ease-in-out infinite; }

@media (prefers-reduced-motion: reduce) {
  .activity-line { animation: none; stroke-dashoffset: 0; }
  .current-week-pulse { animation: none; }
}
```
