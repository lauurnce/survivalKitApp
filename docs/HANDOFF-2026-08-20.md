## 7. New traps from this session

Everything in the 08-10 handoff §6 still applies. Added:

- **A brief's stated pass bar can be arithmetically wrong.** The 694/698 discrepancy
  would have failed Task 12 against correct code. This is the second instance of a
  self-contradicting brief in this build. **Check a brief's numbers against a
  measurement before dispatching, not after a false failure.**
- **A shared working tree is not yours alone.** A peer session switched branches
  mid-task. Nothing was lost only because everything was committed first. **Commit
  before long dispatches, and use `git worktree` rather than switching a tree another
  session is live in.** `ListAgents` shows peers and whether they are busy.
- **`&& echo done` is not verification.** A `cd` persisted across bash calls and made a
  relative-path ledger append fail silently while the trailing echo still printed
  success. Use absolute paths for ledger writes, and re-read the file to confirm.
- **A wrong payload key fails silently in both directions.** A nested field read flat
  yields `undefined`; a flat field read via `.rows` also yields `undefined`. Neither
  throws, and neither fails typecheck if the interface is wrong in the matching way.
  Task 10 shipped `raw.demand.source` for `raw.demand.by_source` — its own verification
  table had the name right, so the slip happened between checking and writing. **Only
  cross-referencing the shipped file against the source catches this class.** Self-
  review structurally cannot.
- **Session limits killed two agents and escalated between them.** Instruct long-form
  agents to append each finished section to disk as they go. Both surviving reports in
  this session did that and lost nothing.
