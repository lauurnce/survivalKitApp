## Risks for reviewers (ordered)

1. **Caching-behavior shifts tests cannot catch (top priority).** Next 16
   silently changes image defaults (minimumCacheTTL 60s→4h) and keeps GET
   route handlers uncached-by-default. The share card's
   `Cache-Control: public, max-age=31536000, immutable` header is set
   explicitly in app/api/card/progress/route.tsx and is unaffected, but verify
   real responses post-deploy (see verification below). No fetch() calls in
   lib rely on framework caching defaults.
2. **ForBlocksCheckout derived-selection refactor** (`8c19798`): stored
   `subjectId` state can now hold a stale id from a previous year until the
   user picks again; every read goes through the `selectedSubjectId`
   fallback, so rendered output/payloads are identical. Reviewers should
   confirm they agree there is no read of raw `subjectId` outside the select's
   onChange setter.
3. **UniversityCombobox latest-ref timing**: ref write moved from render body
   to an effect declared before its consumer effect, so per-commit ordering is
   unchanged — but this now depends on effect declaration order rather than
   render-time assignment.
4. **Eight inline rule suppressions** (`ba12431`): each carries a reason;
   reviewers should sanity-check the claims (e.g. that fetch-on-mount helpers
   really only set state post-await).
5. **middleware.ts kept on Edge with deprecation warning**: intentional;
   proxy.ts migration belongs to the secrets track. Warning is cosmetic noise
   in every build until then.
