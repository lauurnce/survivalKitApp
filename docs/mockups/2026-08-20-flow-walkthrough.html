01

What Is an Array?

An array is a collection of elements of the same type, stored in contiguous memory and reached by index. Declaring one fixes its length for its lifetime.

Indexing starts at zero, so the last valid index of an array of length n is n − 1. Reading past that is the single most common source of runtime crashes in first-year code.

Declaring and Initialising

You can size an array up front and fill it later, or give it values immediately and let the compiler count them for you.

Q1. Given int a[5] = {2,4,6,8,10}; what does a[5] evaluate to?

Answer: undefined behaviour — a[5] is out of bounds. Valid indices are 0..4. Reading it may crash or return garbage; the compiler will not stop you.
