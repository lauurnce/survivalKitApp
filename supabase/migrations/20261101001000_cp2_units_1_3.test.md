## Rollback

There is no delete in the migration, so a rollback restores the old rows
from the step-0 backup:

```sql
update sections s
set kind = b.kind, heading = b.heading, body_md = b.body_md, sort_order = b.sort_order,
    ide_language = b.ide_language, starter_code = b.starter_code
from backup_cp2_unit1_20261101 b
where s.id = b.id;
```

Then:

```sql
update modules set title = 'Unit 1: Arrays', slug = 'unit-1-arrays'
where id = 'a3000001-0001-0002-0001-000000000001';
update modules set sort_order = 2
where id = 'a3000001-0001-0002-0001-0000000000e1';
delete from sections where id = 'a3000002-0001-0002-0001-000000000001';
delete from modules where id in ('a3000001-0001-0002-0001-000000000002',
                                 'a3000001-0001-0002-0001-000000000003');
```

Deleting the two modules removes their sections by cascade (and any reader progress rows that reference them). Drop `backup_cp2_unit1_20261101` once the lessons are confirmed live. Put Exam Prep
back at 2 only if Lessons 4-7 are not live; otherwise leave it at 99.
