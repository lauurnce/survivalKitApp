## Rollback

```sql
delete from modules where id in (
  'a3000001-0001-0002-0001-000000000004',
  'a3000001-0001-0002-0001-000000000005');
```

Sections cascade with their module, and so does every other row that
references these module ids (unlocks, progress, feedback). Run the rollback
only before readers have used the lessons, or copy those rows first. Nothing
else was changed, so nothing else needs restoring.
